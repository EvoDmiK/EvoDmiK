## 🙋‍♂️ About Me

컴퓨터 비전부터 LLM·Agent까지 다양한 AI 모델을 학습하고 서비스에 적용해 온 **AI 엔지니어 김종민**입니다.

- 🎯 **모델 성능 개선**과 **추론 최적화**, **데이터·학습 파이프라인 구축**을 경험했습니다.
- 🕸️ 최근에는 개인 프로젝트로 **지식 그래프 + LLM 기반 질의응답 서비스**를 개발하고 있습니다.
- ✍️ 공부한 내용은 [기술 블로그](https://dove-nest.tistory.com/)에 기록하고 있습니다.
